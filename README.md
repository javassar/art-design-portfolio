# Jacqueline Adelmann — Art & Spatial Design Portfolio

> **Spatial Design · Materiality · Creative Technology & Behavioral Analytics**  
> An interactive web portfolio exploring how built spaces guide human movement, how analog materials ground attention, and how quantitative analysis models real-world interaction.

---

## Overview

This repository contains the interactive portfolio and curatorial archive of **Jacqueline Adelmann**. The collection bridges tangible, physical craft with analytical problem-solving—spanning architectural drafting, ergonomic cardboard prototyping, hand-embroidered fiber arts, and quantitative pedestrian flow modeling.

### Core Focus Areas

- **Spatial Interaction & Behavioral Modeling:** Empirical pedestrian movement studies, vector slope fields, definite calculus integration, and architectural spatial capacity planning.
- **Materiality, Form & Light:** Scale topography, laminated industrial cardboard ergonomics, wood dowel structural framing, and ambient daylight studies.
- **Slow Craft & Everyday Rituals:** Hand embroidery on raw canvas, charcoal on corrugated strata, and investigations into human habit and physical tools.

## Portfolio Web Experience

The web presentation (`portfolio/index.html`) is a standalone, dependency-free application featuring:

- **Filterable Gallery:** Categorized sorting across *Spatial & Interaction*, *Materiality & Form*, and *Slow Craft & Habit*.
- **Curatorial Dossier Modals:** Conceptual breakdowns, material specifications, and analytical narratives for each piece.
- **Interactive Choreographic Canvas:** A dynamic simulation exploring the pedestrian trajectories and velocity fields of *The Sidewalk Waltz*.
- **Lookbook Print Stylesheet:** Clean `@media print` layout optimized for instant, client-ready PDF export (`Cmd + P`).
- **Dark / Light Modes:** Adaptive warm light palette and high-contrast dark aesthetic.
- **Quick Navigation (`⌘K`):** Integrated command palette for instant search across works.
