# Jacqueline Adelmann — Portfolio & Curatorial Dossier

Welcome to your curated portfolio. This portfolio is positioned for applications to **Creative Technologist and Artist-in-Residence roles, spatial design, and data/operations modeling at mindful technology and hardware companies** (such as *Dumb.co, The Light Phone, Daylight Computer, Teenage Engineering, Punkt, reMarkable*).

## Directory Structure
- `index.html`: The complete, interactive web portfolio. Clean typography, responsive grid, dark/light mode toggle, project filtering, modal lightbox with deep conceptual breakdowns, and a print stylesheet for instant PDF export.
- `images/`: 23 optimized, high-resolution visual assets extracted and cropped from your architecture and AP art portfolios.
- `CURATORIAL_GUIDE.md`: In-depth breakdown of the curatorial discernment, why each piece was chosen, narrative pitch scripts, and interview talking points.

## How to View and Use Your Portfolio
1. **View Locally in Any Browser:**
   Double-click `index.html` or right-click and choose **Open With > Google Chrome / Safari**. It is 100% self-contained and functions offline.
2. **Export to a Client-Ready PDF Lookbook:**
   Open `index.html` in your browser and click the **"Print / Export PDF"** button at the top (or press `Cmd + P`). Select **Save as PDF** in the print dialog. The built-in `@media print` stylesheet automatically hides interactive UI elements, adjusts fonts and borders, and formats the portfolio into a print/PDF deck.
3. **Publish Online (Live Website in 60 Seconds):**
   - **Netlify Drop:** Go to [app.netlify.com/drop](https://app.netlify.com/drop) and drag-and-drop this entire `portfolio` folder. You will get an instant live HTTPS link to put on your resume.
   - **Vercel:** Run `npx vercel` inside this folder or connect via GitHub.
   - **GitHub Pages:** Push this repository to GitHub and enable Pages in repository settings.
